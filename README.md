# Viceburg Offline (Android)

Локальная WebView-оболочка для личной Android-версии Viceburg. Приложение не запускает HTTP-сервер и не запрашивает сетевые разрешения. Игровой HTML собирается из `upstream/original/`; тела passages и формат сохранений остаются прежними.

## Состав

- `upstream/original/` — исходная копия игры с двумя целевыми правками: расширенный редактор читов и 20-минутный кулдаун инициативы NPC.
- `android/` — Android-проект (Kotlin, WebView, SAF для папки Media, импорт/экспорт сохранения).
- `localization/` — каталог строк, глоссарий, этапы и инвентаризация перевода.
- `tools/` — воспроизводимые скрипты извлечения строк и сборки HTML.
- `tests/` — статические регрессионные проверки.
- `.github/workflows/android.yml` — CI-сборка и подпись APK по GitHub Secrets.

## Локальный запуск

Открыть `android/` в Android Studio с JDK 17 и Android SDK 35+. Сборка: `gradle :app:assembleDebug`. Рекомендуемая версия Android для проверки: Android 17; проект устанавливает `minSdk 26`, `targetSdk 35`.

Для CI подпись настраивается секретами `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Keystore не хранится в репозитории. CI проверяет наличие всех секретов и завершится ошибкой, если подпись не настроена.

## Media и сохранения

Верхняя панель приложения убрана. На экране `Start` и в редакторе персонажа/меню читов есть компактный блок для выбора папки `Media`, экспорта и импорта сохранения. Доступ к ресурсам сохраняется через SAF; оригинальные медиа не включены в репозиторий. Реальная работа меню, SAF и воспроизведение файлов требуют проверки на телефоне.

## Редактор читов

Редактор игрока и NPC показывает числовые поля из игровых объектов `status`, `attributes`, `progression`, `sexExperience`, `body` и `behavior.mood`. Диапазоны для значений и полей отношений берутся из реальных `min`/`max` объектов игры. Для отношений доступны Friendship, Love, Sex, Fear, Anger и Corruption. Схема сохранений не меняется.
