# Viceburg Offline (Android)

Локальная WebView-оболочка для личной Android-версии Viceburg. Приложение не запускает HTTP-сервер и не запрашивает сетевые разрешения. Игровой HTML хранится в `android/app/src/main/assets/game/index.html`; исходная копия находится в `upstream/original/` и не изменяется.

## Состав

- `upstream/original/` — неизменённый исходник.
- `android/` — Android-проект (Kotlin, WebView, SAF для папки Media, импорт/экспорт сохранения).
- `localization/` — каталог строк, глоссарий, этапы и инвентаризация перевода.
- `tools/` — воспроизводимые скрипты извлечения строк и сборки HTML.
- `tests/` — статические регрессионные проверки.
- `.github/workflows/android.yml` — CI-сборка и подпись APK по GitHub Secrets.

## Локальный запуск

Открыть `android/` в Android Studio с JDK 17 и Android SDK 35+. Сборка: `gradle :app:assembleDebug`. Рекомендуемая версия Android для проверки: Android 17; проект устанавливает `minSdk 26`, `targetSdk 35`.

Для CI подпись настраивается секретами `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Keystore не хранится в репозитории. CI проверяет наличие всех секретов и завершится ошибкой, если подпись не настроена.

## Media

При первом запуске выберите именно папку `Media` через системное окно Android. Доступ сохраняется через SAF. Файлы читаются напрямую из выбранного DocumentTree по относительным путям игры. Ничего не копируется и не загружается на сервер.

## Статус

HTML пересобирается командой `python tools/build_game.py`. Каталог содержит 1 941 точная фраза, 120 контекстных правил и 7 шаблонов. Все 463 строки справки, найденные инвентаризатором, включены в каталог; соответствие фактическим DOM-текстовым узлам и вычитка в WebView ещё не завершены. По последней оценке, точным переводам соответствуют 1 492 из 5 634 извлечённых строк-кандидатов; это приблизительная метрика, не полный процент покрытия. Перевод всей игры не закончен: сюжетные сцены, квесты и динамические диалоги в основном остаются на английском. См. `localization/progress.json` и `localization/README.md`.

Python-регрессии и Node-проверка словаря проходят. Исходные тела passage остаются неизменными в HTML-сборке. APK не собирался: в среде нет Android SDK/Gradle. На Samsung Android 17 не проверены сборка, выбор Media через SAF, кодеки WebView, полноэкранное видео и круговой импорт/экспорт сохранения.
