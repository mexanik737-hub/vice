# Очерёдность перевода

Пакеты этапов отсортированы по зависимостям. Каждый пакет хранит исходную строку, контекст passage, перевод, статус редакторской проверки и связанные плейсхолдеры. Переводы применяются только к видимому DOM-тексту; скрытые `tw-storydata` и исходные тексты passage исключены из обхода.

Этапы: L1 интерфейс; L2 механики и предметы; L3 задания и события; L4 диалоги; L5 регрессия и динамические шаблоны. Все этапы остаются незавершёнными, пока не будет проверена игра целиком.
