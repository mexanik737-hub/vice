# Журнал разработки Viceburg Offline

Дата обновления: 26 ноября 2026 года.

## Выполнено в проекте

- Создан структурированный проект на основе неизменённого `upstream/original/viceburg_mod_clean.html`.
- WebView открывает игру из локальных assets. Разрешение `INTERNET` и HTTP-сервер не добавлялись; внешние сетевые переходы запрещены.
- Выбор папки `Media` реализован через системный Android SAF с прямым чтением через `ContentResolver`; добавлены MIME-типы и ответы по byte range для видео.
- Реализованы полноэкранное HTML5-видео, локальные сохранения в `localStorage`, импорт и экспорт JSON через SAF.
- Сохранены Cheats, исправления генератора NPC и исходные имена passages для совместимости сохранений.
- Добавлены синтетические тестовые JPEG, WebM VP8/Vorbis и WAV PCM.
- Подготовлен GitHub Actions workflow для статической проверки, debug APK и подписанного release APK при наличии секретов подписи.
- Словарь содержит 1 693 точных фразы, 120 контекстных правил и 7 шаблонов. Добавлены переводы FAQ, интерфейса настроек, подсказок к ночному заданию и отдельных сюжетных сцен.
- Откровенные сцены, попавшие в переведённые фрагменты, переведены прямо, без цензуры и пропуска содержания.

## Статус перевода и обнаруженные проблемы

- Инвентаризатор извлёк 5 959 строк-кандидатов (5 634 уникальные). С точными фразами каталога совпадают 1 311, или 23,3%; оставшиеся 4 323 не сопоставлены. Это не точная доля локализованной игры: извлекатель даёт ложные срабатывания на код и пропускает динамически собранный текст.
- Перевод игры **не завершён**: значительная часть интерфейса, механик, предметов, квестов, системных сообщений и диалогов остаётся на английском. В частности, не завершены меню создания персонажа, инвентарь, тюремные механики и большая часть сюжетных сцен.
- Строки переводятся на уровне видимого DOM; код, идентификаторы, имена passages и пути ресурсов не подменяются. Динамические фразы и согласование по роду/падежу требуют дальнейшей сверки в запущенной игре.
- При переводе откровенных сцен не применялась цензура. Контент оригинальной игры не менялся.
- APK не собирался: пользователь будет собирать его самостоятельно. SDK/Gradle и физическое устройство Samsung Android 17 в этой среде отсутствуют.

## Аудит запросов медиа и дополнительный перевод
