## 2026-11-26 — начальная реализация

### Выполнено
- Структура исходного файла, локализации, инструментов, Android-проекта, тестов и CI создана.
- Исходник скопирован в `upstream/original/`; его SHA-256 записан в `localization/progress.json`.
- Инвентаризатор обработал 1 486 passage и создал 4 727 строк-кандидатов в 890 passage.
- Каталог содержит 473 точных перевода, 120 контекстных правил и 7 динамических шаблонов (текущее покрытие; справка FAQ переведена частично) (проверять актуальные числа в `localization/progress.json`).
- Node.js проверил подстановку точных строк и переменных в шаблонах.
- `ffprobe` распознал синтетические JPEG/WebM VP8+Vorbis/WAV PCM ресурсы.

- Добавлен полноэкранный режим HTML5-видео через WebChromeClient.
- Добавлены SAF-выбор дерева Media, прямое чтение через `ContentResolver`, Range-ответы для видео, и действия импорта/экспорта localStorage.
- Добавлены GitHub Actions для тестов и подписанного Release APK при наличии всех четырёх signing secrets.

### Проверки в этой среде
- Android SDK/Gradle отсутствуют; компиляция Kotlin, APK и эмуляторные тесты пока не запускались.
- Локальная попытка Chromium smoke-test невозможна: launcher установлен, но ожидаемый исполняемый файл браузера отсутствует.
- Реальный SAF-провайдер, Samsung Android 17, кодеки WebView и диапазонные запросы видео на устройстве не проверялись.
- Строковый инвентарь консервативный: включает ложные срабатывания, пропускает текст, сформированный динамически.

### Найденные технические риски
- Игра содержит относительные ссылки `Media/...`; выбор SAF-папки должен совпадать с корнем `Media`, чтобы относительные пути разрешались.
- В игре есть сторонние/сетевые упоминания и AI-чатовые точки входа. Приложение не запрашивает сетевое разрешение, поэтому сетевые функции исходной игры недоступны.
- Импорт и экспорт на данный момент копируют `localStorage`; перед утверждением совместимости нужно подтвердить фактическое расположение всех игровых сохранений и провести круговой тест на устройстве.

## 2026-11-26 — исправление стартовой задержки

- Причина тяжёлого старта в локализационном runtime: начальный TreeWalker обходил весь document, в том числе скрытый Twine source; MutationObserver повторно сканировал родительские деревья при изменении каждого текстового узла.
- Исправление: обход только видимых контейнеров игры, изменение отдельных текстовых узлов и пакетная обработка мутаций через `requestAnimationFrame`.
- 7/7 Python-тестов и Node.js runtime-тест пройдены. Это проверяет структуру и логику runtime, но не реальный старт на Samsung/WebView. Системный Chromium в среде отсутствует, поэтому браузерный smoke-test не состоялся.
